## 🌟 About the Project

**AAROH Physiotherapy & Rehabilitation** is a modern healthcare website designed to create a strong digital presence for a physiotherapy and rehabilitation clinic.

The website provides patients with an easy way to:

* 🩺 Explore physiotherapy services
* 👨‍⚕️ Learn about healthcare professionals
* 📋 Understand available treatments
* 📅 Request an appointment
* 💬 Submit enquiries and suggestions
* 📞 Find clinic/contact information
* 📱 Access the website from any device

The primary focus of the project is **professional design, smooth user experience, responsiveness, accessibility, and easy navigation**.

# 🚀 Getting Started

Follow these steps to run the project locally.

## 1️⃣ Clone the Repository

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
```

## 2️⃣ Navigate to the Project

```bash
cd AAROH-PHYSIOTHERAPY
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Start Development Server

```bash
npm run dev
```

The application will start on the local development server provided by Vite.

---

# 🔐 Environment Variables

If the application uses APIs, backend services or databases, create a `.env` file.

Example:

```env
VITE_API_URL=your_api_url
MONGODB_URI=your_database_url
```

### ⚠️ Important

**Never commit private API keys, passwords, database credentials or secret tokens to GitHub.**

Add `.env` to `.gitignore`:

```text
.env
.env.local
```
